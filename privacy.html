에스 노트 개인정보처리방침

시행일: 2026년 10월 23일

1. 어떤 정보를 다루나요

  • 노트 내용·그림·첨부 파일: 사용자가 쓴 노트는 사용자 본인의 구글 드라이브 “에스 노트” 폴더에만 저장돼요. 에스 노트 운영자의 서버에는 저장하지 않아요.
  • 구글 드라이브 권한: drive.file 권한만 사용해요. 에스 노트가 직접 만든 파일만 읽고 쓸 수 있고, 드라이브의 다른 파일은 볼 수 없어요.
  • 로그인 유지 정보: 다시 로그인하지 않도록 구글이 발급한 갱신 열쇠를 암호화해서 사용자 브라우저의 쿠키에만 보관해요. 서버의 데이터베이스에는 저장하지 않아요. 로그아웃하면 지워지고 구글에서도 취소돼요.
  • 기기 보관함: 빠르게 열고 인터넷이 끊겨도 쓸 수 있도록 노트 사본을 사용자 기기의 브라우저 저장소에 보관해요.

2. 다른 곳으로 보내는 정보

  • 맞춤법 검사·AI 도우미: 사용자가 그 버튼을 눌렀을 때만, 그 페이지의 글을 처리하기 위해 OpenAI API로 보내요. 결과를 받은 뒤에는 따로 보관하지 않아요.
  • 원노트 가져오기: 사용자가 마이크로소프트 계정으로 로그인했을 때만 원노트 내용을 읽기 전용으로 가져와요.
  • 그 밖에 노트 내용을 광고·분석·판매 등에 쓰거나 제3자에게 주지 않아요.

3. 구글 사용자 데이터 사용 방침

에스 노트가 구글 API로 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 정보 지우기

  • 노트: 구글 드라이브의 “에스 노트” 폴더를 지우면 모두 지워져요.
  • 권한 취소: 구글 계정 → 타사 앱 연결에서 에스 노트를 삭제하면 돼요.
  • 기기 보관함: 브라우저의 사이트 데이터 삭제로 지워져요.

이용약관

  • 에스 노트는 개인 노트 작성을 위한 무료 도구이며, 노트는 사용자 본인의 구글 드라이브에 저장됩니다.
  • 사용자는 자신의 노트 내용에 대한 권리와 책임을 가집니다.
  • 서비스는 있는 그대로 제공되며, 중요한 노트는 구글 드라이브의 백업 기능 등으로 따로 보관하기를 권합니다.
