# 에스 노트

원노트처럼 쓰는 노트 앱이에요. 노트·그림·첨부 파일은 **내 구글 드라이브**의 `에스 노트` 폴더에 저장돼요.

## 할 수 있는 것

- 전자 필기장 → 섹션 → 페이지 (하위 페이지, 끌어서 순서 바꾸기, 다른 섹션으로 옮기기)
- 글자 크기·굵게·기울임·밑줄·취소선·글자 색·형광펜, 제목 1~3, 정렬, 들여쓰기
- 글머리 기호·번호 목록·할 일(체크박스), 표, 그림(붙여넣기·끌어 놓기 가능), 파일 첨부, 링크
- **자동 목록 켜고 끄기**: `1. ` `- ` `[] `를 입력하면 목록으로 바뀌는 기능
  - 홈 탭의 [자동 목록] 버튼이나 설정에서 켜고 끌 수 있어요. 번호·글머리·할 일을 따로 끌 수도 있어요.
  - 바뀐 직후 백스페이스를 누르거나 알림의 [되돌리기]를 누르면 그 한 번만 원래대로 돌아가요.
- **한글·엑셀로 바꾸기** (한글·엑셀 변환 탭)
  - 한글: 이 페이지 또는 섹션 전체를 `.hwpx`로 바꿔요. 한글 2014 이후 버전에서 열려요. 글자 모양, 목록, 표, 그림이 그대로 옮겨져요.
  - 엑셀: 페이지 글을 한 줄씩 넣은 시트와 페이지 안의 표를 시트로 만들어요. 섹션 전체로 바꾸면 페이지 목록 시트도 생겨요.
  - 바꾼 파일은 내려받기 되고, 드라이브 `에스 노트/내보내기` 폴더에도 저장할 수 있어요.
  - 설정의 **자동 변환**을 켜면, 페이지를 고치고 다른 페이지로 넘어갈 때 드라이브에 자동으로 변환해 둬요.
- **노트선** (보기 탭): 좁은 줄 · 넓은 줄 · 모눈. 페이지마다 고를 수 있고, [새 페이지에도 쓰기]로 기본값을 정해요.
- **맞춤법 검사** (검토 탭): AI가 맞춤법·띄어쓰기·문법 오류를 찾아요. 하나씩 [고치기]/[무시]하거나 [모두 고치기]. Ctrl+Z로 되돌릴 수 있어요.
  - [입력할 때 빨간 밑줄]을 켜면 브라우저가 틀린 낱말에 밑줄을 그어요(무료, 바로 표시).
- 모든 노트 검색, 휴대폰 화면, 어두운 화면

## 맞춤법 검사가 동작하는 방식

- 홈페이지(10senter.vercel.app)의 `api/spellcheck.js`가 홈페이지에 설정된 OpenAI 키로 검사해요. `config.js`의 `spellApi`가 그 주소예요.
- 에스 노트에 구글로 로그인한 상태에서만 동작하고, 에스 노트 주소에서만 부를 수 있어서 다른 사람이 API 비용을 쓰지 못해요.
- 특정 계정만 쓰게 하려면 홈페이지 Vercel 프로젝트의 환경변수 `ALLOWED_EMAILS`에 구글 이메일을 넣어요(선택).
- 비용은 페이지 하나 검사에 보통 1원 안팎이에요(작은 모델 사용).

## 1. 구글 드라이브 연결하기 (처음 한 번, 약 20~30분)

구글이 "이 앱이 드라이브를 써도 된다"는 허락 번호(클라이언트 ID)를 줘야 연결돼요. 무료예요.

1. https://console.cloud.google.com 에 노트를 저장할 구글 계정으로 들어가요.
2. 위쪽 프로젝트 선택 → **새 프로젝트** → 이름 `에스 노트` → 만들기.
3. 왼쪽 메뉴 **API 및 서비스 → 라이브러리**에서 `Google Drive API`를 찾아 **사용**을 눌러요.
4. **API 및 서비스 → OAuth 동의 화면**(또는 "Google 인증 플랫폼")
   - 사용자 유형: **외부**
   - 앱 이름 `에스 노트`, 지원 이메일·개발자 이메일에 내 이메일
   - 범위(데이터 액세스)에 `.../auth/drive.file`을 추가해요. "이 앱이 만든 파일만" 보는 권한이라 구글 심사가 필요 없어요.
   - **테스트 사용자**에 노트를 쓸 구글 계정(내 계정)을 추가해요.
   - 테스트 상태에서는 테스트 사용자로 등록한 계정만 로그인할 수 있어요. 다른 계정으로도 쓰려면 **앱 게시(프로덕션으로 푸시)**를 누르세요. `drive.file` 권한만 쓰기 때문에 심사 없이 게시돼요.
5. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - **승인된 자바스크립트 원본**에 아래 두 개를 넣어요.
     - `http://localhost:5190` (내 컴퓨터에서 미리 볼 때)
     - `https://내-주소.vercel.app` (2단계에서 생기는 실제 주소. 나중에 추가해도 돼요)
   - 만들기 → 나오는 **클라이언트 ID**(`…apps.googleusercontent.com`)를 복사해요.
6. `config.js`를 열어 따옴표 안에 붙여 넣어요.
   ```js
   googleClientId: '1234-abcd.apps.googleusercontent.com',
   ```
   클라이언트 ID는 비밀번호가 아니라서 공개돼도 괜찮아요. 위에서 등록한 주소에서만 작동해요.

## 2. 인터넷에 올리기 (Vercel, 무료)

지금 홈페이지와 같은 방식이에요.

1. GitHub에 새 저장소(예: `drive-note`)를 만들고 이 폴더의 파일을 올려요.
2. https://vercel.com → **Add New → Project** → 그 저장소 선택.
   - Framework Preset: **Other**, 빌드 명령 없음 → Deploy.
3. 생긴 주소(예: `https://drive-note.vercel.app`)를 1단계 5번의 **승인된 자바스크립트 원본**에 추가해요.
4. 휴대폰에서는 그 주소를 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

## 원노트 가져오기 준비 (처음 한 번, 약 10분)

원노트 내용을 통째로 옮기려면 마이크로소프트가 "이 앱이 원노트를 읽어도 된다"는 허락 번호(클라이언트 ID)를 줘야 해요. 무료예요.

1. https://entra.microsoft.com 에 **원노트를 쓰는 마이크로소프트 계정**으로 로그인해요.
   - 개인 계정(outlook.com·hotmail 등)으로 들어갔을 때 "디렉터리가 없다"거나 접근할 수 없다고 나오면, https://azure.microsoft.com/free 에서 무료 계정을 먼저 만들어야 할 수 있어요. 본인 확인 때문에 카드 정보를 묻지만 요금은 나가지 않아요.
2. 왼쪽 **애플리케이션 → 앱 등록 → + 새 등록**
   - 이름: `에스 노트`
   - 지원되는 계정 유형: **모든 조직 디렉터리의 계정 및 개인 Microsoft 계정** (개인 원노트를 쓰려면 꼭 이것)
   - 리디렉션 URI: 플랫폼 **단일 페이지 애플리케이션(SPA)**, 주소 `https://drive-note-chi.vercel.app/ms-auth.html`
   - **등록**
3. 왼쪽 **인증** → 단일 페이지 애플리케이션 아래 **URI 추가** → `http://localhost:5190/ms-auth.html` → **저장**
4. 왼쪽 **API 사용 권한 → + 권한 추가 → Microsoft Graph → 위임된 권한** → `Notes.Read` 체크 → **권한 추가**
   - 원노트를 **읽기만** 하는 권한이에요. 원노트 내용은 바뀌지 않아요.
5. 왼쪽 **개요**의 **애플리케이션(클라이언트) ID**(`xxxxxxxx-xxxx-…` 모양)를 복사해서 `config.js`의 `msClientId` 따옴표 안에 넣어요.

그다음 앱의 **설정 탭 → 원노트에서 가져오기**를 누르면 돼요.

- 전자 필기장을 골라서 섹션·페이지(하위 페이지 포함)·글·표·목록·할 일·그림·첨부 파일을 옮겨요.
- 원노트에서 글상자를 여기저기 놓았던 페이지는 위에서 아래 순서로 차례대로 정리돼요.
- 펜으로 쓴 손글씨는 원노트가 내보내 주지 않아서 빠질 수 있어요.
- 중간에 멈춰도 다시 누르면 이미 가져온 페이지는 건너뛰고 이어서 가져와요.

## 프로그램으로 설치하기

링크로 들어가지 않고 바탕화면·시작 메뉴·홈 화면에서 바로 여는 방법이에요. 앱의 **설정 탭 → 💻 프로그램으로 설치**를 눌러도 돼요.

- 컴퓨터(크롬·엣지): 주소창 오른쪽 끝 설치 아이콘, 또는 메뉴 → 앱 설치
- 안드로이드(크롬): ⋮ → 홈 화면에 추가 → 설치
- 아이폰(사파리): 공유 버튼 → 홈 화면에 추가

설치한 앱도 같은 구글 드라이브에 저장해요. 고친 내용을 GitHub에 올리면 설치한 앱도 다음에 열 때 자동으로 새 버전이 돼요.

## 내 컴퓨터에서 미리 보기

```bash
node serve.js
```

그다음 http://localhost:5190 을 열어요.

## 알아 두면 좋은 것

- **로그인**: 브라우저 창을 새로 열 때마다 [구글로 로그인]을 한 번 눌러야 해요. 구글 보안 정책상 로그인 창은 버튼을 눌러야 열려요. 한 번 허락한 뒤에는 창이 잠깐 떴다 바로 닫혀요.
- **저장**: 쓰는 동안 1초쯤 뒤에 자동으로 저장돼요. 인터넷이 끊기면 이 기기에 임시로 보관했다가 다음에 열 때 되살릴지 물어봐요.
- **지우기**: 페이지·섹션을 지우면 드라이브 **휴지통**으로 가요. 30일 안에는 드라이브 휴지통에서 되살릴 수 있어요.
- **여러 기기**: 다른 기기에서 바뀐 목록은 창으로 돌아올 때 자동으로 불러와요. 다만 **같은 페이지를 두 기기에서 동시에** 고치면 나중에 저장한 쪽이 남아요.
- **백업**: 노트가 내 드라이브에 일반 파일(`페이지/*.html`, 그림, 첨부)로 저장돼서, 앱이 없어져도 드라이브에서 직접 열어볼 수 있어요.
- **체험 모드**: 구글 연결 없이 이 기기 브라우저에만 저장하는 모드예요. 나중에 드라이브로 바꾸면 [저장 위치 → 이 기기에 있던 노트를 드라이브로 옮기기]로 옮길 수 있어요.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html`, `css/app.css` | 화면 |
| `js/app.js` | 전자 필기장·섹션·페이지, 저장, 검색, 설정 |
| `js/editor.js` | 편집기: 서식, 자동 목록, 할 일, 표, 그림·파일 |
| `js/store.js` | 저장소: 구글 드라이브 / 이 기기 |
| `js/hwpx.js`, `js/hwpx-template.js` | 한글(.hwpx) 변환 |
| `js/xlsx.js` | 엑셀(.xlsx) 변환 |
| `js/onenote.js`, `ms-auth.html` | 원노트 가져오기 |
| `js/doc.js` | 노트 내용 읽기·정리 (공용) |
| `config.js` | 구글 클라이언트 ID |
| `manifest.webmanifest`, `sw.js`, `icons/` | 프로그램으로 설치하기 (앱 이름·아이콘·빠른 실행) |
| `serve.js` | 내 컴퓨터 미리 보기용 서버 |
